# Security policy

Please report security vulnerabilities in any Moatgator repository or service privately to **security@moatgator.com** (English or Portuguese). Do not open a public issue.

- The full coordinated disclosure policy, scope and safe harbor are at <https://www.moatgator.com/trust#disclosure>.
- Machine-readable contact: <https://www.moatgator.com/.well-known/security.txt>.
